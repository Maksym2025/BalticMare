# BalticMare / Royal Baltic

## Project heartbeat

This repository is an active development project for **Royal Baltic / BalticMare**, a B2B seafood marketplace focused on European business customers.

The project is actively being developed across the frontend, backend, database and infrastructure layers. Supabase is used as a core backend/database service, with GitHub Actions and Vercel used for development and infrastructure automation.

## Why this repository exists

BalticMare is being built as a real B2B platform, not as a static demo. Planned functionality includes:

- B2B customer registration and approval
- Customer-specific pricing and customer categories
- Seafood product catalogue and logistics data
- Orders and customer accounts
- Payment and invoicing integrations
- Administration tools
- EU-focused B2B operations

## Infrastructure note

Supabase is a critical part of the project. Automated heartbeat activity may be used to keep the development database active while the project is being built.

Please treat repository activity and database activity as signs of an actively maintained development project.

## Current status

Development is ongoing. Architecture, database schema, pricing logic, catalogue structure, authentication, RLS policies, testing and deployment are being implemented incrementally.
